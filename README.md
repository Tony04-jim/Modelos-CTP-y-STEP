# Operación Pika-Rescate: El Reino de los Procesos de Prueba

Juego educativo sobre los modelos de proceso de pruebas de software **CTP** (Critical Testing Processes) y **STEP** (Systematic Test and Evaluation Process), para el curso de Pruebas de Software.

Bowser y Mewtwo encerraron a Pikachu en el Castillo de los Bugs. Recorre 8 mundos aprendiendo la teoría, responde las preguntas, abre las 8 cerraduras y derrota a Bowser en la batalla final.

## Cómo jugar
- Abre `index.html` en el navegador, o visita la página de GitHub Pages del repositorio.
- Todo funciona en un solo archivo (HTML, CSS y JavaScript), sin instalar nada.
